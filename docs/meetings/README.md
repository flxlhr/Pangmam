# Meeting-Notizen

Wir treffen uns jeden Donnerstag. Das Protokoll schreibt jede Woche eine andere Person.
Eine Datei pro Treffen: `JJJJ-MM-TT.md`, z. B. `2026-11-19.md`.

Vorlage:

```markdown
# Treffen JJJJ-MM-TT

**Dabei:** …

## Rückblick letzter Sprint
- Was ist fertig? Was hängt?

## Entscheidungen
- … (wichtige auch in ../entscheidungen.md eintragen)

## Nächster Sprint
- Wer nimmt welches Issue?
```
